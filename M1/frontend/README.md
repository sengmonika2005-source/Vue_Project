# ShareMhob frontend

Vue 3 + TypeScript + Vite, Vue Router, Pinia, Vitest, ESLint, and Prettier.

## Start

```sh
npm run dev
```

Run these commands from `M1/frontend/`. The installed dependencies have been
preserved. For a fresh checkout without `node_modules/`, run `npm ci` once first.

Demo login: `cook@sharemhob.test` / `Cook123!`.

## Checks

```sh
npm run type-check
npm test
npm run lint
npm run format:check
npm run build
```

Read the [root README](../../README.md) and [M1 implementation notes](../docs/m1-implementation.md)
for full scope and acceptance checks. Mock data lives in memory and resets on refresh.
